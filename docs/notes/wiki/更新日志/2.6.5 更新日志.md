# YSM 2.6.5 更新日志

**性能与稳定性**
- 修复 Linux 和安卓端长时间运行易卡死的问题；
- 改进渲染器调度，轻微提升性能，降低在安卓端的负载和功耗；
- 优化不透明模型的渲染；改进模型内存管理；
    - 注意：模型一旦使用半透明材质，渲染效率将大幅降低，建议尽可能减少半透明的使用；

**兼容性**
- 适配 Minecraft 26.1.2 NeoForge；
- 在联动模组版本过低时自动禁用联动功能（而不是报错退出）；

**功能**
- 添加配置项支持禁用部分事故高发的联动功能
    - 比如精妙背包、跑酷（怨声载道……）等反复变动核心代码的模组
- 提高轮盘配置界面的稳定性；
- 添加长矛动画的支持，动画分类名为 `lance`；

**Bug 修复**
- 修复部分 Molang 事件失效的问题；
- 修复自定义矿车模型未正确应用 pitch 旋转的问题；
- 修复预览模型和纸娃娃渲染部分情况下旋转异常的问题；
- 修复部分模型的拔刀剑组定位和 tacz 手枪动画问题；
- 修正女仆使用 YSM 模型时在娱乐方块上遁地的问题；

**模型更新**
- 更新模型：迷你酒狐、圣女酒狐、精灵酒狐、幸存者酒狐、K螺；
